Orosmo est un moteur de jeu 2D et 3D open source (Apache-2.0) écrit en C++23, développé par Timothé Sandt. Le rendu
passe par une couche d'abstraction graphique (le RHI) qui a deux backends, Vulkan et OpenGL 4.3 ; un backend Metal est
prévu et n'existe pas encore. L'interface s'écrit dans un langage maison, le `.cui`, compilé en C++ ; son apparence vient
de thèmes JSON.

[Installer](/demarrer/installation/) · [Code sur GitHub](https://github.com/TimotheSandt/Orosmo) ·
[À propos](/projet/a-propos/) · [Fonctionnalités](/projet/fonctionnalites/)

## État

La version courante est la 0.7.0 : le moteur s'installe une fois par machine, avec une commande, sans vcpkg. Le jalon M8
est livré : scène à entités, simulation à pas fixe rejouable, logique de jeu et vues `.cui` rechargées à chaud sans redémarrage
(le monde est conservé ; pour l'interface, voir [ce qui est gardé](/guides/interface/rechargement-vues/)), façade `app::Application`, navigation au clavier et à la manette, outils de debug ; en plus de M6 (glTF 2.0,
matériaux PBR, éclairage par environnement, animation, foules) et du cœur du rendu de M5 (graphe de passes, forward+,
ombres, HDR, anticrénelage, culling GPU, 2D). L'API peut encore changer entre deux versions mineures.

Linux est la seule plateforme vérifiée. Windows et macOS sont compilés par la CI mais n'ont pas été observés pour le code
récent. La liste complète, avec
les preuves, est sur la page [État du moteur](/projet/etat/).

## Commencer

Pour écrire un jeu ou une application, lisez dans cet ordre :

1. [Installer Orosmo](/demarrer/installation/) : une commande installe l'outil `orosmo` et le moteur précompilé.
2. [Créer un projet](/demarrer/premier-projet/) : `orosmo init`, puis `orosmo run`.
3. [Lire la boucle d'une application](/demarrer/premiere-application/) : les pièces du projet de départ et les conventions des exemples.
4. [Un jeu 3D de bout en bout](/demarrer/tutoriel-jeu-3d/) : un programme complet qui assemble glTF, caméra, ombres et menu.
5. [Explorer la démo](/demarrer/demo/) : une commande par fonction du moteur.

Pour modifier le moteur lui-même, [compilez le dépôt](/demarrer/compiler-le-moteur/).
