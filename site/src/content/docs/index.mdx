Orosmo est un moteur 3D et 2D générique écrit en C++23. Le rendu passe par une couche d'abstraction graphique (le RHI) qui
a deux backends, Vulkan et OpenGL 4.3 ; Metal n'existe pas encore. L'interface s'écrit dans un langage maison, le `.cui`,
compilé en C++ ; son apparence vient de thèmes JSON.

## État

La version courante est la 0.6.0. Le jalon M6 est livré : import glTF 2.0, matériaux PBR, éclairage par environnement,
animation par squelette et foules instanciées, en plus du cœur du rendu de M5 (graphe de passes, forward+, ombres,
HDR, anticrénelage, culling GPU, 2D). L'API peut encore changer entre deux versions mineures.

Linux est la seule plateforme vérifiée. Windows et macOS sont compilés par la CI mais n'ont pas été observés pour le code
récent. Il n'y a pas de scène à entités, pas de logique de jeu rechargeable, pas de manettes. La liste complète, avec
les preuves, est sur la page [État du moteur](/projet/etat/).
