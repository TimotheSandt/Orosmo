# M2 lots B1 et B2 : pipeline de shaders et fenêtre du RHI (`dev`)

Deux sous-lots du lot B de M2 (plan et décision A28 : `docs/05`, `docs/QUESTIONS.md`). Ils **ajoutent** au RHI sans toucher au rendu hérité : la démo et la capture de référence sont inchangées. La réécriture des façades de rendu commence au sous-lot B3. M2 n'est pas terminé et **n'est pas proposé à `main`**.

## Ce qui est livré

| Sous-lot | Élément | Où |
| --- | --- | --- |
| B1 | GLSL 450 « style Vulkan » → SPIR-V (shaderc) → réflexion et traduction GLSL 430 (SPIRV-Cross) : `(set, binding)` → `set * 8 + binding`, push constants → UBO 24 | `include/engine/rhi/shader_compiler.hpp`, `src/rhi/shader_compiler.cpp` |
| B1 | `#include` (résolveur de fichiers), macros, erreurs `fichier:ligne`, refus des liaisons hors des 3 groupes × 8 et des textures/échantillonneurs séparés | idem |
| B1 | `ShaderCache` mémoire + disque (clé = source prétraité), `ShaderHotReloader` (fichier et includes surveillés, erreur de compilation signalée sans perdre l'ancien shader) | idem |
| B1 | dépendance `spirv-cross` (vcpkg, toutes plateformes), bibliothèques ajoutées à `tools/engine-sdk/engine.mk` | `vcpkg.json` |
| B2 | le périphérique OpenGL **adopte une fenêtre** : `prepareWindowHints` avant la création, backbuffer = framebuffer 0 (RGBA8 linéaire, sRGB coupé), `beginFrame`/`present`/`resize`/`setVSync` | `include/engine/rhi/device.hpp`, `src/rhi/opengl/` |
| B2 | le backbuffer est l'unique attachement de sa passe, non échantillonnable, sans envoi de texels ni mips (refus testés) | `src/rhi/README.md` |
| B2 | fixture de test partagée `tests/rhi/gpu_fixture.hpp` | |

Mesuré sous Linux (g++ 13.3, Mesa 26.1.6, Intel Arc, OpenGL 4.6 core) depuis un **clone propre de `dev`** (voir `docs/BASELINE/tests-M2-B2.txt`).

## Limites connues (voir `docs/GAPS.md`, G73 à G75)

- **Windows et macOS** : le code **compile** (CI) mais ni les tests GPU ni ceux de fenêtre ne s'y exécutent (G67). L'ajout de `spirv-cross` à `vcpkg.json` **n'a pas été construit sur ces plateformes** : à observer à la CI du prochain push (le cache vcpkg de la CI sera vide, les jobs seront longs).
- Fenêtre invisible dans les tests ; fenêtre réduite (`kBusy`) et vsync mesuré non couverts (G73, G74).
- Les shaders du dépôt sont encore en GLSL 430 (migration en B4) ; `Game` ne présente toujours pas via le RHI (B4).

## Commande de démo

```bash
make demo-test                                                    # 269 cas
apps/demo/bin/tests/tests -ts="rhi/shader*"                       # pipeline de shaders (B1)
apps/demo/bin/tests/tests -ts="rhi/opengl/window"                 # fenêtre adoptée, présentation (B2)
make rhi-demo RHI_DEMO_ARGS="--out /chemin/image.png"             # démo du lot A, toujours valable
```

Il n'y a pas de démo graphique de B2 à lancer à la main : une fenêtre RHI visible demanderait GLFW dans `apps/`, ce que la règle d'isolation interdit ; la démo applicative présentera via le RHI à partir de B4.
