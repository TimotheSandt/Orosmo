## Pas fait, et pourquoi

- **CI verte sur Windows et Linux : non démontrée.** Le workflow existe mais n'a jamais tourné (pas de GitHub ni de Windows/macOS ici) ; les jobs Windows/macOS sont `continue-on-error` et sans `-Werror`. Le critère « terminé » de `docs/05` pour M0 n'est donc **pas atteint** tant que tu n'as pas vu un run : voir `docs/QUESTIONS.md` A18.
- **Windows et macOS non vérifiés** (build, chemins, installeurs).
- **clang-tidy et clang-format non exécutés** (outils absents de cette machine) ; pas en CI.
- **Fuites ASan non triées** (`detect_leaks=0`) : singletons statiques et contexte GL.
- **Vulkan** : non touché (décision A1), sauf deux contournements de compilation ; `--capture` le refuse (33 erreurs de validation et image différente d'OpenGL, `GAPS.md` G29).
- **Terrain de la démo** : graine d'horloge sans `--seed` (règle 9) ; correction en M1.
- **Migration vers `docs/03`** (arborescence, noms) : au fil des jalons (A2/A17), pas de renommage de masse.
- Dépendance à installer : `sudo apt install doctest-dev` (A5).
- **Disque** : `/` à 97 % (A19).
