# M2 lot B6 : bascule de la démo, retrait de l'ancien rendu, isolation bloquante (`dev`)

Dernier sous-lot du lot B de M2 (plan et décision A28 : `docs/05`, `docs/QUESTIONS.md`). **La démo présente maintenant par le RHI**, l'ancienne couche graphique est supprimée, et la règle d'isolation des API est bloquante pour `gl*`, `Vk*` et `MTL*`. Le lot C (`platform::Window`, mode sans fenêtre, entrées) reste à faire : M2 n'est pas terminé et **n'est pas proposé à `main`**.

## Ce qui a changé

| Élément | Détail |
| --- | --- |
| `Window` | ne connaît plus aucune API graphique : `Init(beforeCreate)` initialise GLFW (rappel d'erreur journalisé), pose ses attributs de fenêtre puis appelle un rappel (l'application y met `rhi::prepareWindowHints`) ; plus de liaison `IWindowGraphicsBinding`, plus de `SwapBuffers` (le RHI présente) ; `Window::Terminate()` |
| `Game` | crée le périphérique en adoptant la fenêtre, puis `ShaderLibrary`, `PipelineCache`, `SceneRenderer`, `CanvasRenderer` ; image composée (scène, puis interface par `Manager::Collect`) copiée sur le backbuffer ; touches de debug 1 à 8 reprises ; captures `scene.png` (cible de scène) et `ui.png` (image composée) comme avant ; destruction dans l'ordre inverse de la création |
| `World`, `Grid`, `TerrainGenerator` | le terrain produit des données de maillage (`MeshData`) ; `World` crée le `Mesh` et le `LightManager` du RHI |
| `CameraController` (nouveau, dans la démo) | reprend `Camera::Inputs` (clavier, souris, fil de fer) : la caméra du moteur ne lit aucune entrée (G80) |
| Minuteries GPU | `ProfilerGpuTimerFactory` : le `Profiler` mesure en GPU par horodatages dans l'encodeur courant ; `Profiler::ClearGpuQueries()` avant de détruire le périphérique (sinon plantage à la sortie, trouvé et corrigé) |
| Ligne de commande | `--api vulkan` et `metal` répondent « not available yet (Vulkan: M4, Metal: M9) » (RHI-04) |
| **Supprimé** | `IGraphicsDevice` et les backends OpenGL, Vulkan, Metal ; `GraphicsRenderState` ; `Buffer`, `Texture`, `RenderTarget`, `ShaderProgram`, `ShaderLibrary`, `Mesh`, `Sprite`, `Light`, `Camera`, `Renderer`, `Renderer2D`, `Renderer3D`, modes d'upscale, `Screenshot`, `GPUTimestampQuery`, `AccelerationStructure`, shaders d'origine ; chemin de dessin immédiat de l'interface (`Draw`, `Sprite`, `RenderTarget` des conteneurs, `Manager::Render`), partie graphique de `TextRenderer`. **−16 800 lignes** ; tout reste dans l'historique git, étiquette **`archive/pre-M2-B6-legacy-graphics`** (A1 : « conservé en archive ») |
| Isolation des API | `tools/check_api_isolation.py --graphics-only --strict` (dans `make check` et la CI) : **0 infraction**, aucun `gl*`, `GL_*`, `Vk*`, `MTL*`, glad, vulkan hors de `src/rhi/` ; GLFW et `<windows.h>` restent en baseline (7 fichiers) jusqu'au lot C (G88) |
| Documentation | `docs/RHI.md` (guide d'ensemble : couches, image de bout en bout, règles, preuves), `src/Graphics/README.md` réécrit, `docs/GRAPHICS_BACKENDS.md` marqué obsolète |

## Preuves

- **`scene.png` de la démo** (`--capture`) est **identique** à `docs/BASELINE/reference/scene-opengl-seed1-1280x720.png` : 0 pixel d'écart, écart max 0/255, depuis un clone propre de `dev` (`789d583`, voir `docs/BASELINE/tests-M2-B6.txt`).
- **`ui.png` de la démo** : la scène, le panneau de performances, les deux boîtes et le texte sont ceux de l'ancien rendu ; les valeurs (FPS, durées) varient d'une exécution à l'autre, donc la comparaison exacte se fait avec le texte figé, par `tests/renderer/parity_tests.cpp` (0 pixel d'écart, B5). Les durées GPU du panneau sont non nulles après 200 images (minuteries du RHI).
- La démo se ferme proprement (code 0) et le journal ne contient aucun message d'erreur de la couche de validation OpenGL.
