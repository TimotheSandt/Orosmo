# v0.6.2 : distribution du SDK (`feat/SDK-integ`)

## Résumé

Décision **A76** de l'auteur (2026-11-25) : le moteur s'installe **une fois par machine**. Un installeur (`install.sh`,
`install.ps1`) installe les paquets système après confirmation, l'outil `orosmo` dans `$OROSMO_HOME/bin` (ajouté au `PATH`) et
le moteur précompilé dans `$OROSMO_HOME/engines/<version>` ; un projet nomme sa version (`OROSMO_VERSION` dans `config.mk`)
au lieu de copier le moteur. Les bibliothèques tierces du moteur sont précompilées dans `deps/` du paquet : **ni vcpkg ni
`make install`** pour le développeur. **Aucun code C++ du moteur touché** ; le jeu livré aux joueurs ne change pas.

## Changements incompatibles

- Aucun changement d'API du moteur.
- Projets existants avec `orosmo/` : compilent toujours ; `orosmo migrate` les passe au moteur installé.
- `Generated/` est dans le projet (`ENGINE_GEN_DIR`), plus dans `ENGINE_DIR` ; CMake : `OROSMO_GEN_DIR` = `<build>/orosmo_generated`.
- `make install` d'un projet n'installe plus les dépendances du moteur.
- Linux : glibc ≥ 2.39 (outil `orosmo` : GLIBC_2.39 ; archives du paquet : 2.38) (Ubuntu 24.04 et plus récent).

## Commande de démo

```bash
make e2e-init                                   # paquet extrait en lecture seule -> orosmo init -> build sans vcpkg -> lancement
curl -fsSL https://github.com/TimotheSandt/Orosmo/releases/latest/download/install.sh | sh   # après publication
orosmo init mygame && cd mygame && orosmo run
```
