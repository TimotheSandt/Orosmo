# M2 lot B3 : couche de ressources de rendu sur le RHI (`dev`)

Troisième sous-lot du lot B de M2 (plan et décision A28 : `docs/05`, `docs/QUESTIONS.md`). Il écrit la **nouvelle** couche de ressources, explicite et sans état global, au-dessus du RHI. **Elle coexiste avec les anciennes façades** : la démo, la capture de référence et tout le code hérité sont inchangés. M2 n'est pas terminé et **n'est pas proposé à `main`**.

## Écart au plan, à connaître

Le plan prévoyait de réécrire `Buffer`, `Texture`, `RenderTarget`, `ShaderProgram` / `ShaderLibrary`, `Screenshot` et `GPUTimestampQuery` en place et de supprimer `GraphicsRenderState` en B3. Les réécrire en place aurait cassé la compilation de `Mesh`, `Sprite`, `Light`, `Renderer*`, du texte et de l'interface (leurs consommateurs, B4 et B5) à chaque commit. J'ai donc écrit des classes **nouvelles** (`engine::renderer`) et déplacé **la suppression des anciennes en B6** ; le tableau de `docs/05` et `docs/GAPS.md` (G77) le disent. Contrepartie : jusqu'en B6, le dépôt a deux couches de ressources, et seule l'ancienne est branchée sur la démo.

## Ce qui est livré

| Élément | Où |
| --- | --- |
| `GpuBuffer` : tampon RAII (`create`, `update`, `read`, `resize` avec ou sans contenu) | `include/engine/renderer/gpu_buffer.hpp` |
| `Texture` : 2D RAII + échantillonneur ; mips selon `FilterMode` ; `upload`, `resize`, `readback`, `fromFile` (stb, RGBA8, retournée comme l'ancien chargeur) | `texture.hpp` |
| `RenderTarget` : MRT + profondeur (lisible ou non), `passDesc`, `resize` / `reconfigure` sans fuite (la cible reste valide si la recréation échoue), lecture de texels depuis le coin haut gauche | `render_target.hpp` |
| `ShaderLibrary` / `ShaderProgram` : GLSL 450 depuis fichiers ou sources, réflexion fusionnée des étages (conflit de type refusé), cache disque, **rechargement à chaud** branché | `shader_library.hpp` |
| `PipelineCache` : un pipeline par (programme, révision, état fixe) ; un rechargement détruit les pipelines périmés | `pipeline_cache.hpp` |
| `Image` : `readImage` (RGBA8/BGRA8, origine en haut), `savePng` / `loadPng`, `compareImages` | `image.hpp` |
| `GpuTimer` : deux horodatages, `isReady` / `elapsed` sans blocage | `gpu_timer.hpp` |
| Ajouts au RHI : `Device::textureDesc`, `Device::timestampsReady`, `createShaderFromCompiled`, cache optionnel dans `ShaderHotReloader` | `include/engine/rhi/` |
| Archive `librenderer.a`, règle de couche `renderer`, README du module | `mk/engine.mk`, `tools/layers.json`, `src/renderer/README.md` |
