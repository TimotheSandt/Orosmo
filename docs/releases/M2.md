# M2 : RHI, backend OpenGL, couche de rendu, plateforme (lots A, B et C)

Jalon livré côté code sur `dev`. Détail par sous-lot : `docs/releases/M2-lotA.md`, `M2-B2.md` à `M2-B6.md` ; ce document couvre le **lot C** et l'état final du jalon. Guide d'ensemble : `docs/RHI.md`.

## Lot C : ce qui a changé

| Élément | Détail |
| --- | --- |
| `Window` | déplacée en `include/engine/platform/window.hpp` + `src/platform/window.cpp` (`git mv` séparé). GLFW n'apparaît plus dans l'en-tête : `void *GetWindow()` (poignée opaque pour `SurfaceDesc::nativeWindow`), `RequestClose`, `ShouldClose`, `GetFramebufferSize`, `GetContentScale` (DPI), `SetCursorMode`, `Get/SetCursorPosition`. Les trois constructeurs paramétrés, déclarés mais jamais définis, le sont maintenant. |
| `InputManager` | déplacé en `include/engine/platform/input_manager.hpp` + `src/platform/input_manager.cpp`. `GetInstance(void *)`. **Molette** (`GetMouseScroll`) : cumulée par le rappel GLFW, remise à zéro à chaque `Update` (le `TODO` d'origine disparaît). |
| Démo | plus aucun include GLFW : `CameraController::update(Window &, …)`, `Window::RequestClose`. Tampon d'image à la taille réelle (DPI), interface en coordonnées logiques. Option `--vsync`. |
| Mode sans fenêtre (PLAT-04) | `--headless` : `Game(true)` ne crée pas de fenêtre, périphérique hors écran 1280×720, pas de temps fixe 1/60, aucune entrée ; rend `--capture-frames N` images (10 par défaut), enregistre `--capture <dir>` si demandé, puis quitte. |
| Isolation des API | `tools/baseline/api_isolation.txt` supprimé ; `check_api_isolation.py --strict` (GLFW, `<windows.h>`, `gl*`, `Vk*`, `MTL*`) bloquant dans `make check` et la CI : **0 infraction**. |
| CI | nouveau pas « Headless capture identical to the windowed one » (Linux x64, xvfb). |
| Outils | le générateur `cui` inclut `engine/platform/window.hpp` pour le type `Window`. |

## Preuves

- `make check` : couches 0 violation, **isolation des API 0 infraction sans baseline**, 71 en-têtes autonomes.
- Capture **sans fenêtre** (`main --headless --capture <dir>`) comparée à `docs/BASELINE/reference/scene-opengl-seed1-1280x720.png` : 0 pixel d'écart, écart max 0/255. Capture fenêtrée : idem.
- Tests ajoutés : `tests/platform/window_input_tests.cpp` (poignée, taille de tampon, échelle, fermeture, fenêtre jamais créée, molette), 3 cas de `graphics_api_tests` (`--headless`, `--vsync`).
- Résultats complets et ASan/UBSan : `docs/BASELINE/tests-M2-lotC.txt` (clone propre de `dev`).

## Ce qui n'est PAS prouvé (voir `docs/GAPS.md`)

- G93 : `--headless` demande encore un serveur d'affichage (contexte GLFW invisible).
- G94 : écran à échelle 2 non observé ; G95 : position du curseur, plein écran, sans bordure non testés automatiquement.
- G96 : `Window` et `InputManager` gardent leurs noms globaux jusqu'à la migration de `UI`.
- G67 / G91 : tests GPU et démo non observés sous Windows et macOS (la CI les exécute sans GPU matériel).

## Revue de la PR #7 (CodeRabbit) : corrections avant M3

La revue automatique a relevé environ 90 points sur l'ensemble de M2. Tous ont été vérifiés contre le code ; ceux qui étaient
fondés sont corrigés, chacun avec un test qui vise le défaut relevé (détail : `docs/GAPS.md` G97 à G100). Ces tests n'ont pas été
rejoués un par un sur le code d'avant la correction.

| Lot | Branche | Principales corrections |
| --- | --- | --- |
| G97 | `fix/M2-coderabbit-rhi` | échecs d'allocation, `resize`, limites de textures, rappel de validation, `glDrawBuffer(GL_BACK)`, plage de profondeur, `dispatch`, lecture pendant une passe, cache de shaders, `check_layers.py` (contrôlait à tort rien sous `include/engine/`) |
| G98 | `fix/G98-rhi-opengl` | unité de texture réservée, VAO détachés, clôture GPU par image, limite des SSBO, portées ouvertes à `submit`, plages sans débordement, octets réellement transférés, tranches 3D, barrière de stockage, réflexion des tableaux, rechargement à chaud (includes absents, surveillances conservées), cache disque par processus |
| G99 | `fix/G99-renderer` | identifiant de programme unique, ancien pipeline gardé si une révision ne se lie pas, étages validés ensemble, modes de mise à l'échelle et de génération d'images (initialisation, historique lu avant d'être remplacé, sans RTTI), couches d'interface prémultipliées et gardées, redessin partiel dans l'ordre, normale dans l'espace monde, validations des maillages et cibles, démo en `Result` |
| G100 | `fix/G100-tests-docs` | tests sans `error()` sur un succès, sans horloge, dossiers temporaires exclusifs, `ENGINE_TEST_REQUIRE_GPU`, `make demo-test-unit` / `demo-test-gpu`, MRT à 8 cibles, `make check` bloquant, documentation corrigée |
